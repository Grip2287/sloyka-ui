# Sloyka: панели и админки

Sloyka — это CSS-классы `sl-*` в каскадных слоях и несколько веб-компонентов без зависимостей. Работает в чистом HTML, React, Vue и Astro. Готовую разметку каждого компонента для копирования смотри в `components.md` рядом с этим файлом.

## Подключение
1. Пакет приватный. В проекте нужен `.npmrc` с `@grip2287:registry=https://npm.pkg.github.com` и токеном пользователя (`read:packages`). Токен не коммитить. Если токена нет, попроси пользователя создать его сам: сам токены не вводи.
2. `npm i @grip2287/sloyka@<точная версия>`
3. Подключение со сборщиком: `import '@grip2287/sloyka/css'; import '@grip2287/sloyka';`. Без сборщика: `dist/sloyka.min.css` и `<script type="module" src=".../sloyka.js">`.
4. В `<head>` до стилей вставь однострочник темы из README, чтобы тема не мигала при загрузке.

## Порядок работы
1. **Каркас.** `<sl-shell class="sl-shell">`, внутри `.sl-topbar`, `nav.sl-nav.sl-shell__nav#sl-nav`, `.sl-shell__backdrop[data-sl-nav-close]` и `main.sl-shell__main`. Кнопка меню: `[data-sl-nav-toggle]`. Адаптив уже встроен: от 1200px меню полное, от 768 до 1199px рейл, до 768px выезжающее.
2. **Страница.** `.sl-page-head` с `h1.sl-page-title`, затем `.sl-toolbar` (поиск `.sl-search`, фильтры `.sl-select` с `aria-label`, главное действие справа в `.sl-toolbar__end`), содержимое и `.sl-section-title` между блоками.
3. **Содержимое.** Объекты показывай карточками `.sl-card[data-accent]` с `.sl-kv` внутри сетки `.sl-grid`. Журналы — `.sl-table` с модификатором `--stack` и `data-label` у каждой ячейки. Списки — `<sl-group>` + `.sl-row`. Состояние раздела — `.sl-banner`. Пустой раздел — `.sl-empty`.
4. **Статусы.** Только `.sl-status--ok|warn|crit`, `--hollow` для офлайна. Цвет никогда не единственный признак: рядом всегда есть текст.
5. **Действия.** Главное действие — `.sl-btn--primary`, одно на экран. У иконочных кнопок обязателен `aria-label`. Опасные действия — `.sl-btn--danger`.
6. **Окна.** `<sl-modal id>` + `<dialog class="sl-modal">`, открытие через `[data-sl-open]`. Уведомления — `toast(text, { title, type })`.

## Правила
- Не пиши свои цвета и размеры. Если нужно перекрасить, переопредели токены `--sl-*` в CSS проекта, вне слоёв.
- Не меняй классы библиотеки внутри `node_modules`. Если нужен новый компонент, сначала собери его из существующих классов. Если не получается, предложи пользователю добавить компонент в библиотеку.
- Выбранный пункт меню: `aria-current="page"`. Выбранная строка: `aria-current="true"`.
- Проверь каждую страницу в обеих темах (`data-theme="light"` / `"dark"`) на ширинах 390, 1024 и 1440. Не должно быть горизонтальной прокрутки и обрезанного текста.

## Обновление
Чтобы обновить библиотеку, поменяй версию в `package.json` и пересобери проект. Что изменилось, смотри в CHANGELOG пакета. Чтобы откатить, верни прежнюю версию.
