# Примеры запросов к Claude

Скопируйте запрос, замените `<…>` на своё и отправьте Claude Code в папке будущего сайта.

Перед первым запросом:
- Claude Code: установлен плагин `sloyka` (`/plugin marketplace add Grip2287/sloyka-ui`, затем `/plugin install sloyka@sloyka`);
- Codex, Cursor, Copilot, Gemini CLI: в корне сайта есть `AGENTS.md` со ссылкой на `node_modules/sloyka/agents/sloyka.md` (текст — GUIDE, раздел 9). Запросы ниже подходят любому агенту;
- если нужен свой стиль — название шаблона. Все шаблоны видно в Storybook: «Основа → Все шаблоны».

> **Что умеет библиотека (1.x).** Компоненты 01–24 для **панелей и админок**: кнопки, поля, переключатели, теги, статусы, карточки, таблицы, списки, меню, модалки, уведомления, вход, боковое меню с адаптивом. Сайт собирается **только из них**: свои теги и стили запрещены и ловятся при сборке. Секций **лендинга** (hero, цены, отзывы) и блоков **магазина** (товар, корзина) в библиотеке **пока нет** — см. раздел 3.

## 1. Админ-панель

### Полная панель с нуля
```
Сделай админ-панель «<название проекта>» на Sloyka (скилл sloyka).
Стек: <Vite + React + TypeScript | Next.js App Router>. Пакет: sloyka@<версия>.
Стиль: шаблон «<название шаблона>» (если файла нет — остановись и спроси).
Каркас: 24 Shell + Nav (полное меню на мониторе, рейл на планшете, выезжающее на телефоне),
16 Topbar с ThemeToggle и 18 Menu аккаунта.
Разделы меню:
- Управление: Пользователи, Журнал входов, Журнал событий
- Система: Состояние системы, Логи
- <свои разделы>
Страницы:
1. Вход — 23 Login, ошибка «неверный пароль».
2. Пользователи — 15 PageHeader + Toolbar (Search, Select роли и статуса), 06 Card в Grid с ролью (04 Tag)
   и статусом (05 Status), 21 Modal «Добавить пользователя» с 02 Field, результат — 22 useToast.
3. Журнал событий — 13 Table (время, пользователь, действие со статусом), на телефоне карточками,
   14 Empty при пустом списке.
4. Состояние системы — 10 Stats сверху, 07 Metric карточками, 09 Banner при сбое.
Данные пока моковые, в отдельном файле.
Сначала покажи план: какие номера компонентов где. Потом собери.
В конце: npx sloyka-check src — ноль нарушений, сборка проходит, обе темы на 390/1024/1440.
```

### Добавить страницу в готовую панель
```
Добавь в панель страницу «<название>» (скилл sloyka).
Пункт меню: в раздел «<раздел>», иконка <имя из списка Icon>.
Содержимое: <что показать — таблица / карточки / форма / сводка>.
Действия: <кнопки и что они делают>.
Только компоненты Sloyka. Если чего-то не хватает — скажи, чего именно, и не собирай из тегов.
```

### Поменять тексты, данные, вкладки
```
На странице «<название>»: переименуй <что> в <что>, добавь колонку «<колонка>» в таблицу,
вкладки <А, Б, В> сделай через 03 Segmented. Вид компонентов не трогай.
```

### Подключить реальные данные
```
Подключи страницу «<название>» к API <адрес или описание>. Загрузка — 14 Empty с текстом «Загрузка…»,
ошибка — 09 Banner tone crit, успех действия — 22 useToast. Компоненты и вёрстку не меняй.
```

## 3. Лендинг или магазин

В Sloyka пока нет секций лендинга и блоков магазина, а собирать их из своих тегов в проекте на Sloyka нельзя. Варианты:

**Внутренняя часть на Sloyka.** Кабинет клиента, админка магазина, панель заказов — это обычная админка (раздел 1):
```
Сделай админку интернет-магазина «<название>» на Sloyka (скилл sloyka):
Заказы — 13 Table со статусами (05 Status) и фильтрами (15 Toolbar);
Товары — 06 Card в Grid, 21 Modal редактирования с 02 Field и 14 Dropzone для фото;
Сводка — 10 Stats и 07 Metric.
```

**Публичная витрина** (лендинг, каталог, корзина) — отдельный проект без Sloyka (скилл `frontend`), либо запрос владельцу библиотеки:
```
Каких компонентов Sloyka не хватает для лендинга «<тема>»? Составь список для владельца библиотеки:
название, где используется, что внутри, пример. Ничего не верстай.
```

## 4. Обновление библиотеки

```
Обнови sloyka до <версия> (скилл sloyka). Сначала покажи, что нового и где лежит, и жди моего «да».
Потом обнови, прогони sloyka-check и сборку, исправь то, что стало нарушением.
```

Откат:
```
Верни sloyka на версию <версия> и пересобери.
```
