# Примеры запросов к Claude

Скопируйте подходящий запрос, замените `<…>` на своё и отправьте Claude Code в **пустой папке будущего сайта**.

Перед первым запросом в этой папке должно быть:
- плагин `sloyka` установлен: `/plugin install sloyka --marketplace Grip2287/sloyka-ui`;
- файл `.npmrc` с вашим токеном (см. README → «Установка»). Если его нет, Claude создаст файл и попросит вставить токен самому;
- название шаблона, если нужен свой стиль. Все шаблоны видно в Storybook: «Основа → Все шаблоны».

> **Что умеет библиотека сейчас (0.1.x).** Компоненты и каркас для **панелей и админок**: кнопки, поля, переключатели, теги, статусы, карточки, таблицы, списки, меню, модалки, уведомления, вход, боковое меню с адаптивом. Готовых **секций лендинга** (hero, цены, отзывы) и **магазина** (карточка товара, корзина, оформление заказа) в ней **пока нет**. Для лендингов и магазинов Claude берёт из Sloyka стиль и общие элементы, а недостающие блоки верстает сам на токенах `--sl-*`. Такие блоки при обновлении библиотеки поменяются только в цветах и размерах.

## 1. Админ-панель

### Полная панель с нуля
```
Сделай админ-панель «<название проекта>» на библиотеке Sloyka (скилл sloyka).
Пакет: @grip2287/sloyka@<версия>, .npmrc с токеном уже в папке.
Стиль: по шаблону «<название шаблона>» (если шаблона нет — остановись и спроси).
Стек: Vite + чистый HTML/JS.
Каркас: sl-shell — полное меню на мониторе, рейл на планшете, выезжающее на телефоне; переключатель темы и меню аккаунта в верхней панели.
Разделы меню:
- Управление: Пользователи, Журнал входов, Журнал событий
- Система: Состояние системы, Логи
- <свои разделы>
Страницы:
1. Вход (sl-login) с проверкой полей и ошибкой «неверный пароль».
2. Пользователи — фильтры (поиск, роль, статус) + карточки с ролью и статусом, модалка «Добавить пользователя».
3. Журнал событий — таблица (время, пользователь, действие со статусом, подробности), на телефоне карточками, пустое состояние.
4. Состояние системы — баннер «работает штатно», карточки нагрузки процессора/памяти/диска.
Данные — правдоподобные заглушки в одном файле data.js, без Lorem ipsum.
Не пиши свои цвета и размеры — только классы sl-* и шаблон.
В конце проверь обе темы на 390, 1024 и 1440 и пришли скриншоты.
```

### Одна новая страница в готовой панели
```
В этой панели на Sloyka добавь раздел «<название>» в боковое меню (группа «<группа>»).
На странице: заголовок, панель фильтров (<какие>), главная кнопка «<действие>», ниже <таблица | карточки> с полями: <поля>.
По кнопке открывается модалка с формой: <поля формы>; после «Сохранить» — уведомление toast «<текст>».
Используй только компоненты Sloyka, стиль текущего шаблона не трогай.
```

### Перевести существующую админку на Sloyka
```
Переведи эту админку на Sloyka (скилл sloyka) по шаблону «<шаблон>».
Логику, адреса API и идентификаторы, которые читает JS, не меняй — меняй разметку и классы.
Сначала составь таблицу «старый элемент → компонент Sloyka» и покажи мне, потом переводи по одной странице со скриншотами до/после.
```

## 2. Лендинг (пример: шиномонтаж)

```
Сделай одностраничный сайт для шиномонтажа «<название>» в <город>, адрес <адрес>, телефон <телефон>.
Цель сайта — запись: звонок и форма «Записаться».
Оформление — Sloyka (скилл sloyka) по шаблону «<шаблон>»: цвета, шрифт, кнопки, поля, карточки, модалка, уведомления — из библиотеки.
Секций лендинга в Sloyka пока нет: hero, услуги и цены, как мы работаем, отзывы, вопросы-ответы, контакты с картой, липкая панель «Позвонить / Записаться» на телефоне —
сверстай скиллом frontend, но только на токенах --sl-* (без своих цветов, радиусов и размеров).
Услуги и цены: <список, например «Сезонная переобувка R13–R16 — от 1 800 ₽», …>.
Форма записи: имя, телефон с маской +7, марка авто, дата, согласие на обработку данных; после отправки — toast «Заявка отправлена».
Тексты — правдоподобные под нишу, где нужен текст от заказчика — помечай <!-- TODO -->.
Проверь обе темы на 390, 1024 и 1440, Lighthouse на телефоне ≥ 90, пришли скриншоты.
```

Под другую нишу меняется только первая строка и список услуг: автосервис, салон, клиника, курсы и т.д.

## 3. Интернет-магазин

```
Сделай интернет-магазин «<название>» (<что продаём>) на Sloyka (скилл sloyka) по шаблону «<шаблон>».
Стек: Vite + чистый HTML/JS, без бэкенда: товары в products.json, корзина в localStorage.
Из Sloyka — каркас шапки, кнопки, поля, переключатели, теги («Хит», «Скидка»), бейджи-счётчики (корзина), модалки, уведомления, таблица (история заказов).
Блоков магазина в Sloyka пока нет: карточка товара, сетка каталога, фильтры-сайдбар, страница товара с галереей, корзина, оформление заказа —
сверстай скиллом frontend только на токенах --sl-* и классах sl-*, без своих цветов и размеров.
Страницы:
1. Каталог — фильтры (категория, цена, наличие), сортировка, сетка карточек (фото, название, цена, «В корзину»), на телефоне фильтры в выезжающей панели.
2. Товар — галерея, цена, характеристики (sl-kv), «В корзину», похожие товары.
3. Корзина — список, количество, итог, «Оформить».
4. Оформление — контакты, доставка (sl-segmented), оплата, согласие; после — страница «Заказ принят».
Данные — 12–20 правдоподобных товаров с заглушками фото.
Проверь обе темы на 390, 1024 и 1440 и пришли скриншоты.
```

Админка магазина (заказы, товары, остатки) делается запросом из раздела 1: это как раз то, для чего Sloyka сделана.

## 4. Стиль, шаблоны и референсы

**Сайт по готовому шаблону**
```
Подключи к этому сайту шаблон «<шаблон>» из @grip2287/sloyka (templates/<файл>.css) после стилей библиотеки и убери все свои переопределения цветов и размеров, которые с ним спорят. Пришли скриншоты до/после.
```

**Новый стиль с другого сайта**
```
Разбери референсы (скилл sloyka-references).
```
(Сначала добавьте референс в Storybook: «Референсы → Добавить референс». Шаблон с его названием создастся сразу.)

**Сделать шаблон под заказчика**
```
Сделай для заказчика «<имя>» шаблон на основе «<базовый шаблон>»: главный цвет <цвет>, скругления <px>, кнопки на 10% крупнее. Сохрани как «<Имя шаблона>» и покажи превью в «Все шаблоны».
```

## 5. Обновления

**Выпустить новую версию библиотеки** (в репозитории sloyka-ui)
```
Выпусти обновление Sloyka: <что изменилось, например «кнопки скруглённее в шаблоне 1»>.
```
Claude запишет изменения, прогонит проверки и отправит на GitHub. Публикация начнётся после Merge запроса «Version Packages».

**Обновить сайт до новой версии** (в папке сайта)
```
Обнови @grip2287/sloyka до <версия>. Покажи, что поменялось по CHANGELOG, пересобери сайт и пришли скриншоты до/после в обеих темах. Если что-то сломалось — откати на прежнюю версию и опиши проблему.
```

**Проверить, есть ли обновления**
```
Проверь, есть ли новая версия @grip2287/sloyka, и коротко перескажи, что в ней изменилось.
```
